# Frontend Implementation Plan

> **Goal:** Build a public + admin web frontend for the Repertorio Semana Santa app — hermandad browsing, member management, procesion lifecycle, marcha catalog, and cruceta editor.

**Architecture:** Next.js 14 App Router with TypeScript, Tailwind CSS, shadcn/ui components, NextAuth v5 for Keycloak OIDC auth. BFF pattern (JWT in httpOnly cookie, server-side API calls to Gateway). Mobile-first responsive design.

**Tech Stack:** Next.js 14.2, TypeScript (strict), Tailwind CSS, shadcn/ui, NextAuth v5, TanStack Query, pnpm, Vercel (deploy).

**Existing API:** 18 endpoints across 3 services (hermandad, procesion, repertorio) behind Gateway on port 8080. Auth via Keycloak OIDC (issuer-uri: localhost:8180/realms/semana-santa).

## Deploy

- **Platform**: Vercel (free tier — 100GB bandwidth, 100h serverless compute)
- **Connect**: GitHub repo → auto-deploy on push to main
- **Env vars**:
  - `NEXTAUTH_SECRET` — random string for session encryption
  - `NEXTAUTH_URL` — deployment URL
  - `KEYCLOAK_CLIENT_ID` — `semana-santa-client`
  - `KEYCLOAK_ISSUER` — `http://localhost:8180/realms/semana-santa` (dev) or Cognito URL (prod)
  - `GATEWAY_URL` — `http://localhost:8080` (dev) or `https://api.example.com` (prod)
- **Preview URLs**: Every PR gets unique URL from Vercel
